# 🧠 MoodFlow Ultra

A full-stack mental health tracking web app that helps users log moods, analyze stress levels, and get smart suggestions.

---

## 🚀 Features
- 🔐 User authentication (Register / Login)
- 📊 Live dashboard with charts
- 😊 Mood tracking system
- 🧠 Smart AI-like suggestions
- 🎨 Modern SaaS UI (glassmorphism + animations)
- 🔊 Interactive UI feedback (sound + animations)

---

## 🛠 Tech Stack
- Node.js + Express
- HTML / CSS / JavaScript
- Chart.js
- Express Session
